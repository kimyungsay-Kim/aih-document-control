# AIH Document Control

หน้าเว็บสำหรับดูทะเบียนเอกสาร (Document Control Status) โครงการ AIH

- หน้าเว็บนี้ไม่มีข้อมูลโครงการเก็บไว้ในตัว
- เปิดครั้งแรกให้ใส่ลิงก์แชร์ไฟล์ Excel จาก OneDrive ลิงก์จะถูกจำไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น
- ไฟล์ Excel ถูกอ่านในเบราว์เซอร์ ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์อื่น
